# 🛒 Lulu Retail - Waste Reduction Project
### Saving Rs 2.6 Crore from Expired Products

**Problem:** Lulu Hypermarket losing Rs 2.6 Crore due to expired products. 260,153 units at HIGH risk.

**Solution We Built:**
1. Analysis: Found Dairy & Grocery waste most, Kochi-02 store highest risk
2. Dashboard: Created 4 graphs showing risk, category, store, expiry
3. Action Plan: Dynamic Discount + Donation + Transfer between stores
4. Result: Saved 2,08,122 units = Rs 2,08,12,200

**Tech Used:** Python, Pandas, Matplotlib

**Files:**
- `lulu_raw_data.csv`
- `lulu_waste_dashboard.py`
- `lulu_solution_plan.py`

Run: `python solution.py`
