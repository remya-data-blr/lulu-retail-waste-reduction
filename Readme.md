# 🛒 Lulu Retail - Waste Reduction Project
### Saving Rs 2.6 Crore from Expired Products

## 📌 Problem Statement
Lulu Hypermarket losing Rs 2.6 Crore due to expired products.
- 260,153 units at HIGH risk
- Dairy & Grocery categories wasting most
- Kochi-02 store has highest waste

## 💡 Solution We Built
1.  **Analysis:** Found root cause - Dairy & Grocery near expiry
2.  **Dashboard:** Created 4 graphs (Risk level, Category, Store, Expiry)
3.  **Action Plan:**
    - Dynamic Discount (70% if 2 days left)
    - Donation to NGO
    - Transfer between stores
4.  **Result:** Saved 2,08,122 units = **Rs 2,08,12,200 saved (80% waste reduced)**

## 🛠️ Tech Stack
Python, Pandas, Matplotlib, Seaborn
